# PS Vita controls

| Vita | Game |
|---|---|
| D-pad, left stick | move |
| Cross | A: shoot (confirms in menus) |
| Square or L | C: special |
| Circle | B: jump / fly |
| Triangle or R | D |
| START | start (free play) |
| SELECT (short press, alone) | pause / resume |

## Option file

An empty file `ux0:data/demonfront/aspect43` shows the picture in 4:3 instead of full screen.
